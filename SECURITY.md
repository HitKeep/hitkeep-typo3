# Security

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/PascaleBeier/hitkeep-typo3/security/advisories/new). Do not include credentials, customer analytics, or exploitable security details in public issues.

For non-sensitive bugs, use [GitHub issues](https://github.com/PascaleBeier/hitkeep-typo3/issues).

This repository contains a source implementation candidate. No stable package release, production acceptance, security certification, or response-time guarantee is claimed.
