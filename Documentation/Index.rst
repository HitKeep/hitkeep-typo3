HitKeep for TYPO3
================

The extension's README.md contains the installation, settings, privacy, cache,
CSP, update, removal, rollback and publication guidance. It is the canonical
operator guide for this source implementation candidate.

Supported runtime qualification: TYPO3 14.3.9, PHP 8.4.24, SQLite.
The Composer range is restricted to TYPO3 14.3.x.
